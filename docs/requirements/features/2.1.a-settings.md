## Feature 2.1.a — Configurações

**Para** controlar custo, segurança e critério,  
**Como** administrador,  
**Quero** configurar o modelo, a chave, os critérios e os exemplos.

**Onda**: 1 (MVP)

**Restrições não funcionais**

- A chave só é gravada, nunca lida de volta: aparecem só os últimos 4 caracteres; nunca em resposta, log ou erro (constituição §VI).
- Critérios e exemplos guardados com versões; o conteúdo inicial vem de `skills/video-corte-vertical/`.
- Comando de CLI equivalente, não interativo, com `--json` e códigos de saída consistentes (constituição §II).

### 2.1.a.1 — Modelo e chave do LLM

Como administrador,

### 2.1.a.2 — Critérios e exemplos versionados

Para calibrar as sugestões.

### 2.1.a.3 — Registrar exemplo pela CLI

Como administrador,  
Quero registrar uma decisão como exemplo pela CLI,  
Para calibrar sem abrir a tela.
