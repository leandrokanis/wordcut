## Feature 1.2.a — Equipe e papéis

**Para** cada pessoa acessar só o que pode,  
**Como** administrador,  
**Quero** liberar e-mails e definir papéis.

**Onda**: 5 (MVP)

**Restrições não funcionais**

- Acesso externo só pelo Cloudflare Tunnel + Access; sem autenticação própria (constituição §VI).
- Dos editores se guarda só o e-mail (LGPD).
- Depende do domínio na Cloudflare (pendente na constituição).
- Comando de CLI equivalente, não interativo, com `--json` e códigos de saída consistentes (constituição §II).

**Permissões por papel**

| Ação | Assistente | Admin |
|---|:-:|:-:|
| Criar a pregação e delimitá-la | ✅ | ✅ |
| Processar (baixar, transcrever, cortar) | ✅ | ✅ |
| Pedir novas sugestões | ❌ | ✅ |
| Escolher ou descartar cortes sugeridos | ✅ | ✅ |
| Forma: grafia (com trava) e estilo da legenda | ✅ | ✅ |
| Conteúdo: faixa do corte, trechos, ordem; criar corte do zero | ❌ | ✅ |
| Exportar e baixar | ✅ | ✅ |
| Apagar pregação ou corte | ❌ | ✅ |
| Configurações e equipe | ❌ | ✅ |
