## Feature 1.1.a — Criar pregação pelo link

**Para** começar pelo culto certo,  
**Como** assistente de edição,  
**Quero** criar a pregação a partir do link da live.

**Onda**: 1 (MVP)

**Restrições não funcionais**

- Comando de CLI equivalente, não interativo, com `--json` e códigos de saída consistentes (constituição §II).

**Histórias de Usuário**

- [1.1.a.1 — Ver dados da live pelo link](#11a1--ver-dados-da-live-pelo-link)
- [1.1.a.2 — Aviso de live não terminada](#11a2--aviso-de-live-não-terminada)

---

### 1.1.a.1 — Ver dados da live pelo link

Como assistente de edição,  
Quero colar o link e ver o título, a data e a duração,  
Para confirmar que é o culto certo.

**Status**: ✅ Feita

**Critérios de aceite**

```gherkin
Cenário: Criar a pregação colando o link
  Dado a lista de pregações
  Quando clico em "Nova pregação", colo o link de uma live terminada e confirmo
  Então a pregação aparece com o título, a data do culto e a duração vindos da live

Cenário: Lista de pregações
  Dado pregações cadastradas
  Quando abro a aplicação
  Então vejo a lista com título, data do culto, duração e estado de cada pregação
  E a mais recente aparece primeiro

Cenário: Mesmo vídeo de novo
  Dado uma pregação já criada a partir de um vídeo
  Quando colo outro link do mesmo vídeo (watch?v=, youtu.be/ ou /live/)
  Então recebo a pregação existente, sem criar duplicata

Cenário: Link inválido
  Dado o diálogo "Nova pregação"
  Quando colo um link que não é de vídeo do YouTube
  Então o motivo aparece junto ao campo
  E nenhuma pregação é criada

Cenário: Falha ao consultar o YouTube
  Dado um link de vídeo inexistente, ou o YouTube fora de alcance
  Quando tento criar a pregação
  Então recebo um erro claro
  E nenhuma pregação é criada

Cenário: CLI equivalente
  Dado um link de live terminada que ainda não foi cadastrado
  Quando o operador roda "wordcut sermon create <link> --json"
  Então recebe o ID, o título, a data do culto e a duração, com "created: true" e saída 0
  E "wordcut sermon list" e "wordcut sermon show <id>" consultam as pregações criadas
```

### 1.1.a.2 — Aviso de live não terminada

Como assistente de edição,  
Quero ser avisado se a live ainda não terminou,  
Para não processar à toa.

**Status**: ✅ Feita

**Critérios de aceite**

```gherkin
Cenário: Criar a pregação de uma live no ar
  Dado uma live que ainda não terminou
  Quando crio a pregação pelo link
  Então a pregação é criada
  E aparece um aviso de que a live não terminou

Cenário: Aviso na tela da pregação
  Dado uma pregação de live que ainda não terminou
  Quando abro o nível da pregação
  Então vejo o aviso de que a live não terminou, sem travar o botão Processar

Cenário: Processar uma live não terminada é recusado
  Dado uma pregação de live que ainda não terminou
  Quando peço para processar
  Então o processamento é recusado porque a live não terminou, sem iniciar tarefa
  E, na web, Processar passa a ficar indisponível, com o motivo

Cenário: CLI equivalente
  Dado uma live que não terminou
  Quando o operador roda "wordcut sermon create <link> --json"
  Então a pregação é criada com "live_finished: false" e o aviso vai para o stderr
```
