## Feature 1.1.a — Criar pregação pelo link

**Para** começar pelo culto certo,  
**Como** assistente de edição,  
**Quero** criar a pregação a partir do link da live.

**Onda**: 1 (MVP)

**Restrições não funcionais**

- Comando de CLI equivalente, não interativo, com `--json` e códigos de saída consistentes (constituição §II).

**Histórias de Usuário**

- [1.1.a.1 — Ver dados da live pelo link](#11a1--ver-dados-da-live-pelo-link)
- [1.1.a.2 — Aviso de live não terminada](#11a2--aviso-de-live-não-terminada)

---

### 1.1.a.1 — Ver dados da live pelo link

Como assistente de edição,  
Quero colar o link e ver o título, a data e a duração,  
Para confirmar que é o culto certo.

---

### 1.1.a.2 — Aviso de live não terminada

Como assistente de edição,  
Quero ser avisado se a live ainda não terminou,  
Para não processar à toa.
