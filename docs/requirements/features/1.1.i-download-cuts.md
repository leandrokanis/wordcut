## Feature 1.1.i — Baixar as exportações

**Para** enviar à revisão do supervisor,  
**Como** assistente de edição,  
**Quero** baixar as exportações de um corte.

**Onda**: 5 (MVP)

**Restrições não funcionais**

- Cada corte guarda o histórico das próprias exportações; não há uma lista separada de vídeos gerados.
- Comando de CLI equivalente, não interativo, com `--json` e códigos de saída consistentes (constituição §II).

### 1.1.i.1 — Baixar uma exportação

Como assistente de edição,  
Quero baixar a última exportação de um corte, ou uma anterior,  
Para enviá-la à revisão do supervisor.
