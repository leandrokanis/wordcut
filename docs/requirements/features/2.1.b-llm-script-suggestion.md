## Feature 2.1.b — Sugestão de cortes pelo LLM

**Para** a equipe não decidir conteúdo,  
**Como** assistente de edição,  
**Quero** receber os cortes sugeridos pelo LLM.

**Onda**: 3 (MVP)

**Restrições não funcionais**

- Uma chamada por pregação, automática ao fim do processamento; nova chamada só pelo administrador (constituição §III).
- Transcrição enviada como frases numeradas, sem tempo; resposta em JSON validado, com uma nova tentativa.
- Prompt montado com o prompt base, o trecho do nível escolhido para cada filtro e valor do preset, os números do formato e as instruções adicionais (constituição §I).
- Comando de CLI equivalente, não interativo, com `--json` e códigos de saída consistentes (constituição §II).

### 2.1.b.1 — Sugestão automática

Como assistente de edição,  
Quero receber os cortes sugeridos automaticamente ao fim do processamento,  
Para não decidir conteúdo.

**Status**: ✅ Feita

**Critérios de aceite**

```gherkin
Cenário: Cortes sugeridos ao fim do processamento
  Dado o modelo e a chave do LLM configurados
  Quando o processamento de uma pregação termina
  Então o LLM é chamado uma única vez, com o preset padrão
  E os cortes válidos aparecem como sugeridos, cada um com título, frases em ordem e uma faixa contínua da pregação

Cenário: Só a pregação vai ao LLM
  Dado uma pregação processada
  Quando a sugestão é pedida
  Então o LLM recebe só as frases da pregação, numeradas e sem tempo, com o prompt do preset

Cenário: Nova tentativa após resposta inválida
  Dado um LLM que responde fora do formato esperado, ou cita frase que não existe, na primeira vez, e certo na segunda
  Quando a sugestão roda
  Então os cortes da segunda resposta são gravados, com duas chamadas no total

Cenário: Duas respostas inválidas
  Dado um LLM que responde fora do formato esperado duas vezes
  Quando a sugestão roda
  Então nenhum corte é gravado e a pregação continua processada
  E o motivo da falha da sugestão aparece na pregação

Cenário: LLM não configurado
  Dado o modelo ou a chave do LLM não configurados
  Quando o processamento termina
  Então a pregação fica processada, sem cortes, com a mensagem dizendo o que falta

Cenário: Corte fora da duração permitida
  Dado uma resposta válida com um corte fora da duração permitida do preset
  Quando a sugestão é gravada
  Então esse corte é descartado com aviso e os outros ficam
```

### 2.1.b.2 — Pedir nova sugestão

Como administrador,  
Quero pedir uma nova sugestão,  
Para quando as primeiras não servirem.

**Status**: ✅ Feita

**Critérios de aceite**

```gherkin
Cenário: Nova sugestão com outro preset
  Dado uma pregação processada com cortes sugeridos, um escolhido e um descartado
  Quando o administrador pede nova sugestão com outro preset
  Então o LLM é chamado com o prompt desse preset
  E os sugeridos não editados são substituídos pelos novos
  E o escolhido, o descartado e os editados permanecem

Cenário: Sugestão não depende da máquina livre
  Dado outra tarefa pesada em andamento
  Quando o administrador pede nova sugestão
  Então a sugestão roda normalmente

Cenário: Falha não apaga os cortes
  Dado uma pregação processada com cortes
  Quando a nova sugestão falha, por duas respostas inválidas ou por LLM não configurado
  Então os cortes anteriores ficam intactos

Cenário: Pedido recusado antes de começar
  Dado uma pregação que não está processada, um preset inexistente ou outra sugestão da mesma pregação em andamento
  Quando o administrador pede nova sugestão
  Então o pedido é recusado com o motivo, sem iniciar tarefa

Cenário: Só o administrador
  Dado um assistente identificado
  Quando pede nova sugestão
  Então o pedido é recusado por falta de permissão

Cenário: CLI equivalente
  Dado uma pregação processada
  Quando o administrador roda "wordcut sermon suggest <id> --preset <p> --wait --json"
  Então o resultado lista os cortes novos
  E, sem "--wait", recebe na hora a tarefa em andamento
```

### 2.1.b.3 — Preset da sugestão

Como administrador,  
Quero saber com qual preset cada sugestão foi gerada,  
Para entender as diferenças.

**Status**: ✅ Feita

**Critérios de aceite**

```gherkin
Cenário: Corte guarda o preset da sugestão automática
  Dado cortes sugeridos ao fim do processamento
  Quando consulto os cortes da pregação
  Então cada corte sugerido traz o preset com que foi gerado, o padrão daquele momento

Cenário: Nova sugestão com outro preset
  Dado uma nova sugestão pedida com outro preset
  Quando consulto os cortes novos
  Então eles trazem esse preset

Cenário: Preset apagado ou corte que não veio do LLM
  Dado um corte cujo preset foi apagado, ou que não veio do LLM
  Quando consulto o corte
  Então ele aparece sem preset

Cenário: CLI equivalente
  Dado uma pregação com cortes sugeridos
  Quando o operador roda "wordcut sermon show <id> --json"
  Então cada corte traz o preset da sugestão
  E o resultado de "wordcut sermon suggest" traz o preset usado
```
