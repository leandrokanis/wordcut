## Feature 1.1.e — Escolher roteiros sugeridos

**Para** editar só o que vale a pena,  
**Como** assistente de edição,  
**Quero** escolher ou descartar os roteiros sugeridos.

**Onda**: 4 (MVP)

**Restrições não funcionais**

- O assistente não altera o conteúdo do roteiro (constituição §I).
- Comando de CLI equivalente, não interativo, com `--json` e códigos de saída consistentes (constituição §II).

**Histórias de Usuário**

- [1.1.e.1 — Ver roteiros sugeridos](#11e1--ver-roteiros-sugeridos)
- [1.1.e.2 — Descartar roteiro](#11e2--descartar-roteiro)

---

### 1.1.e.1 — Ver roteiros sugeridos

Como assistente de edição,  
Quero ver os roteiros sugeridos com o texto montado e a duração,  
Para escolher quais editar.

---

### 1.1.e.2 — Descartar roteiro

Como assistente de edição,  
Quero descartar um roteiro,  
Para ficar só com os que vou usar.
